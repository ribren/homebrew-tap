# ribren's tap

Homebrew casks for my macOS menu-bar apps.

```bash
brew tap ribren/tap
brew install --cask clicker   # Apple TV remote — github.com/ribren/clicker
brew install --cask pingky    # latency heatmap — github.com/ribren/pingky
```

Or in one line, no tap step:

```bash
brew install --cask ribren/tap/clicker
```

Both apps are signed, notarized, MIT-licensed, and live in the menu bar.
